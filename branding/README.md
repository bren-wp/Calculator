# Calculator visual identity

Official brand: **Calculator**. All interface copy is English.

Design language: flat 2D, no perspective or 3D effects, no gradients, no neon, no decorative development labels. The primary brand system uses deep slate, lighter slate surfaces, mint actions and high-contrast typography.

Source design colors: `#101D26`, `#1B2D38`, `#263C48`, `#34505C`, `#F3F8FA`, `#A0B2BD`, `#53E4C5`, `#092921`.

The `screens/` folder contains individual vector design previews for 27 states and screens. These are design assets, not recorded runtime screenshots. The native app renders interactive Compose layouts from the same palette and structure.

Launch: operating-system splash → Standard calculator. No onboarding, sign-in or welcome wizard.

Branding should be compared against actual screenshot captures on the supported device matrix before a 1:1 parity claim.
